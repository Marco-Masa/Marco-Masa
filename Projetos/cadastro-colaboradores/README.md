# 🥇 Cadastro de Colaboradores
## 🚀 Objetivo
- Este projeto em PHP foi criado para criar o sistema de **Cadastro de Colaboradores das Lojas Brincos e Companhia (fictícia)**. O programa solicita o **Nome Completo, Idade, Profissão, Salário Pretendido e Experiências Profissionais** do colaborador e retorna a confirmação do recebimento das informações.
- O sistema possui normalizadores de informações para os campos **Nome Completo e Profissão** convertendo as informações para que tenham sempre a primeira letra de cada string em maiúscula. O campo de **Experiências Profissionais** converte as informações para que tenha sempre a primeira letra da string em maiúscula.
## 🔧 Instruções de Uso:
- Informe o Nome Completo.
- Digite a Idade em anos.
- Informe a Profissão.
- Digite o Salário Pretendido.
- Informe as Experiências Profissionais.
## ✔ Exemplo do resultado:
Nome Completo: Teste
Idade: 35 anos
Profissão: Comerciante
Salário Pretendido: R$ 1.524,35
Experiências Anteriores: Diversos anos com resolução de dificuldades diárias
----------------------------------------
Olá, Teste!
Confirmamos o recebimento dos seus dados.
Registramos que você atua como Comerciante e possui Diversos anos com resolução de dificuldades diárias de bagagem na área.
